v0.2 · macOS 14+ · Apple Silicon · Traitement local

01 LES FORMATS

Deux onglets. Le même geste.

PHOTO

HEIC HDR 10 bits

Règle l’intensité des hautes lumières pour tes photos SDR et vois le résultat avant d’exporter. Les photos déjà HDR conservent leur plage dynamique.

VIDÉO

HLG, PQ ou Dolby Vision 8.4

Exporte en MOV 10 bits. Le mode Dolby Vision ajoute des métadonnées dynamiques à une base Rec. 2100 HLG.

Le rendu de l’aperçu dépend de ton écran. Pour profiter du Dolby Vision, utilise un lecteur compatible avec le profil 8.4.

02 EN PRATIQUE

Du fichier à l’export.

  1. Dépose tes fichiers. Choisis Photo ou Vidéo, puis glisse un média ou tout un lot.
  2. Affiche l’aperçu ou choisis le format. Règle l’intensité HDR dans Photo, ou sélectionne HLG, PQ ou Dolby Vision dans Vidéo. Clique ensuite sur Traiter.
  3. Choisis le dossier d’export. L’app lance le traitement et conserve les originaux.

03 INSTALLATION

Prêt à ouvrir Terminal.

Copie la commande et colle-la dans Terminal. Elle installe ou met à jour HDR Studio dans le dossier Applications de ton compte.

Connecte GitHub CLI une seule fois avec gh auth login et un compte autorisé à accéder au dépôt privé. Si besoin, installe-le avec brew install gh.
